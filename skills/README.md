# Skills para proyectos web y PWA

Guías reutilizables para convertir prototipos en aplicaciones responsivas y publicarlas como PWA estáticas en GitHub Pages.

## Skills

- [PWA responsiva desde un prototipo](./pwa-responsiva/SKILL.md): adaptar pantallas de Stitch u otros prototipos a una aplicación para escritorio y móvil.
- [Deployment confiable en GitHub Pages](./github-pages-pwa/SKILL.md): configurar rutas de repositorio, build, PWA, Actions y diagnosticar errores de despliegue.

Cada skill usa el formato SKILL.md con metadatos de agente. Copia la carpeta skills a otro repositorio o instala las skills en tu directorio de skills.
